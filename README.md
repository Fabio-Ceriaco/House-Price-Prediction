# House-Price-Prediction

In this project, we will build an XG Boost model to predict house prices based on various features.
The dataset used is the Boston Housing dataset, which contains information about housing prices in Boston.
The goal is to predict the median value of owner-occupied homes (in $1000s) based on various features such as crime rate, number of rooms, property tax rate, etc.
I will follow the typical machine learning workflow, including data preprocessing, model training, evaluation, and visualization of results.
